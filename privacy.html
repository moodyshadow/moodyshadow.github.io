Privacy Policy

Last updated: September 2026

This application is a single-operator automation tool for the Daily Overclocked YouTube channel. It does not collect, process, or store personal data belonging to any third party.

The only account data accessed is the operator's own TikTok account information (basic profile identity, via the user.info.basic scope) and the operator's own video content, used solely to publish the operator's own videos to the operator's own TikTok account via the Content Posting API (video.publish scope).

No data obtained through TikTok's API is shared with, sold to, or used by any third party. No data is used for advertising or analytics purposes. Access tokens are stored locally on the operator's own device and are not transmitted anywhere other than to TikTok's own API endpoints.

Questions: see the Daily Overclocked YouTube channel.
